# 原生界面的圆角与间距

所有页面、弹窗和浮层共用 `internal/nativeui/tokens.go`。数值是 1536 × 1024 参考画布上的设计 DIP，绘制时统一乘以 `uiScale`，不对缩放后的物理像素再次取整。

| 层级 | token | 半径 |
| --- | --- | ---: |
| 弹窗 | `radiusDialog` | 32 |
| 主内容外框、结构预览 | `radiusChrome` | 24 |
| 卡片、分组、下拉菜单 | `radiusCard` / `radiusPanel` | 16 |
| 按钮、输入框、列表行 | `radiusControl` / `radiusRow` | 12 |
| 标签、小型嵌套控件 | `radiusChip` | 8 |
| 非圆形控件的最小值 | `radiusMin` | 4 |
| 胶囊、圆点、圆形按钮、滑块 | `radiusPill` | 由短边的一半决定 |

相邻层级的嵌套框用 `nestedRadius(R, p)`，保持内外边缘的圆心一致，最小取 4。尤其不要给选中底色、阴影、裁切层分别指定不同半径。

- 分段选择器：外层 12，内边距 4，选中背景与内部按钮 8。
- 下拉菜单：外层 16，内边距 8，选项 8。
- 结构预览：外层 24，`previewPad` 为 12，模型、高度尺和信息面板均为 12。
- 地图：卡片 16，内边距 8，画布 8。

正文卡片中的独立按钮按控件层级使用 12；`R − p` 用于贴合父容器边缘的内框，而不是按每一层不绘制背景的布局 Row/Column 重复递减。

图标与头像的外框使用 `iconRadius(size, scale)`，按尺寸选择已有的 4 / 8 / 12 / 16 / 24 / 32 token，不再各自使用 20%～30% 的比例。字体大小不会改变按钮圆角。原有胶囊和圆形使用全圆 token；`radiusPill` 是上限标记值，不是实际绘制的半径。

手写 padding、gap 以及原生主题 spacing 使用 4 DIP 网格。涉及文本宽度的手动测量、筛选滑块位置、虚拟列表列间距须使用与布局相同的 spacing token。系统提供的标题栏安全区、动画位置、滚动位置和地图数据坐标保持实际测量值。

## 连续曲线的支持范围

启动器使用 Go / MyGo 原生控件，没有 CSS 层，因而不能执行 `@supports` 或 `corner-shape: superellipse(1.25)`。

当前依赖 MyGo v0.7.4 在 `ui/paint.go` 中只为 macOS 启用其原生 Apple 连续圆角；这不是 CSS `superellipse(1.25)` 的数值实现。Windows D3D11 和 Linux GL 的着色器不支持该曲线，保留普通圆角回退。没有强制修改私有开关、替换绘制器或加入曲线 polyfill。这样填充、边框、阴影、裁切和硬件加速仍沿用同一条绘制路径。

后续应在 MyGo 提供公开的按控件曲线 API，且对应后端支持填充、阴影与裁切时集中启用；届时须为胶囊和圆形明确选择 round，并验证实际 GPU 路径。
