YoloMCL 1.3.1 fixes seed-map compatibility, fluid textures and manual Java selection.

## Seed maps and saved worlds

- Resolve installed Minecraft 26.x biome-preset references using the matching version's builtin data, fixing maps that previously displayed only an empty grid.
- Support 26.2 density and surface-rule formats, including interval selection, preliminary surface heights, biome holder sets and three-dimensional noise conditions.
- Read split 26.1+ world-generation metadata consistently in seed maps, save selection and world summaries. Preserve saved dimension settings, zero seeds and structured spawn positions.
- Hide the seed-map tab and save-list map buttons for enabled mods that change terrain, biome placement or dimensions. Check the selected instance in the background, reuse cached metadata and refresh after mod changes. Vanilla instances and verified non-terrain mod sets retain the map.
- Add an editable teleport height to map-point and structure popups. Copy an explicit `/tp X Y Z` command, defaulting above available terrain or water; height slices retain the selected Y. If no height is available, enter it manually before copying.
- Explain unavailable biome predictions in the map and link to their details.

## Structure-preview materials

- Load water and lava textures from the active resource stack, select the first scheduled animation frame and use still textures on horizontal faces and flowing textures on sides.
- Apply water tint and transparency, render lava without terrain shading and remove shared faces between adjacent fluid blocks.
- Preserve selection of visible blocks beneath transparent water and keep fluid materials correct when changing height cuts.
- Fluid textures currently use a static frame; fluid simulation and animated playback are not included.

## Java selection

- Use a valid manually selected Java even when its major version differs from the game's recommendation. Automatic mode continues to offer installation when the matching runtime is missing.
- Apply visible instance settings before launching or opening another game copy, so an unsaved Java selection cannot trigger an unnecessary download prompt.
- Keep runtime summaries, inherited global/directory choices and installed-Java usage counts consistent with launch behavior.

## Updating

Updates remain optional. Existing official installations can check for the release in Settings. Launcher settings and Minecraft files remain in their existing locations.

For manual installation, download the archive for your operating system and processor: `.zip` for Windows, or `.tar.gz` for macOS and Linux. Extract the complete archive before launching. `amd64` is Intel/AMD x64; `arm64` includes Apple Silicon.

Terrain-derived teleport heights do not include later structures, features or player edits. Seed maps remain experimental; see the [seed map guide](https://github.com/Viking602/YoloMCL/blob/main/docs/seed-map.md) for coverage and limitations.
