YoloMCL 1.1.0 adds modpack export and configurable launcher update policies, and reduces memory, CPU and disk activity across startup and instance management.

## Modpack export

- Export installed instances as Modrinth `.mrpack` or CurseForge `.zip` packages from instance Settings.
- Choose the pack name, version and included content. Worlds, screenshots, server lists and personal options are opt-in.
- Preserve verified platform download references and include local or unidentified files in `overrides/`.
- Stream exports with bounded buffers, report progress in Tasks & Logs, support cancellation and replace existing exports only after the new archive is complete.

## Performance and resource use

- Reuse bounded mod metadata caches across instances through a shared SHA-1 index, and populate caches during installation. Settings includes cache cleanup.
- Reduce temporary allocations and concurrent scanning peaks, including nested JAR inspection, image decoding and large log reads.
- Load overview counts and storage information without a full mod-content scan. Reuse recent storage results, cancel obsolete requests and avoid repeated scans when switching instances.
- Reduce idle polling and startup work, use filesystem change notifications on Windows, and defer background tasks until after the first frame.
- Release inactive page resources and discard discovery results after one minute away from the Discover page.
- Improve scrolling with hardware acceleration disabled and reduce unnecessary redraws while retaining transitions. Initial numeric values fade in; subsequent changes retain their rolling animation.
- Remove the custom startup/graphics plugin and use the upstream MyGo rendering path. Windows continues to default to software rendering, with optional hardware acceleration in Settings.

## Launcher updates

- Check once per launch and show an update dialog with confirmation and cancellation when a new stable version is available.
- Support a publisher-configured minimum supported version for mandatory security updates, authenticated by a separately signed update policy.
- Retain verified policies across restarts and provide retry or manual-download actions when automatic updating is unavailable.
- Keep updates optional in this release. Mandatory-update enforcement applies only to clients that implement the policy feature; it cannot retroactively disable earlier releases.

## Desktop fixes

- Add Java distribution icons to runtime lists and selectors, improve picker responsiveness and preserve provider selection while download options refresh.
- Fix cape previews, account-menu redraws, tooltip wrapping and stale asynchronous page results.
- Show installed content counts in the overview until detailed update information has been loaded.
- Improve image-cache ownership, page cancellation and UI update scheduling during navigation.
- Add regression coverage for caches, cancellation, update policies, exports and platform behavior, plus opt-in tests for startup and real-instance performance.
- Update the architecture documentation and add screenshots to the English and Chinese READMEs.

## Downloads and updates

Choose the package matching your operating system and processor. Windows users should download the `.zip`; macOS and Linux users should download the `.tar.gz`. `amd64` is Intel/AMD x64, and `arm64` includes Apple Silicon. Extract the complete archive before launching.

Existing official installations can check for this release in Settings. Update archives are signature-verified and contain application files and licenses; launcher settings and Minecraft files remain in their existing locations.

Windows executables are not Authenticode-signed. macOS bundles are ad-hoc signed, not notarized. Java auto-download and online-account credential storage retain the [current platform limits](https://github.com/Viking602/YoloMCL#current-platform-limits).
