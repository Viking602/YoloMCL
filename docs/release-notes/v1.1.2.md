YoloMCL 1.1.2 fixes startup failures caused by duplicate library entries in Minecraft version profiles.

## Fixes

- Include each JAR path only once in the launch classpath, preventing Forge and NeoForge startup failures such as `IllegalStateException: Duplicate key` for Gson, Guava and other repeated dependencies.
- Preserve the original dependency order and distinct library versions. Equivalent path separators are handled consistently, and Windows paths are compared without case sensitivity.
- Keep native library downloads and extraction intact when a library is declared more than once.

## Validation

- Add regression tests for duplicate dependencies, alternate path separators, Windows path casing, distinct library versions, launch rules and native library extraction.
- Based on v1.1.1, with only the startup fix and its regression tests.

## Updating

Existing official installations can update from Settings. Updates remain optional.

For manual installation, download the archive matching your operating system and processor: `.zip` for Windows, or `.tar.gz` for macOS and Linux. Extract the complete archive before launching. `amd64` is Intel/AMD x64; `arm64` includes Apple Silicon.
