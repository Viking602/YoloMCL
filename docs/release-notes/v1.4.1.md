YoloMCL 1.4.1 adds in-place Horizon build upgrades and version switching, fixes Horizon mod and shader pack removal with undo, allows installing and managing addons while a game is running, and upgrades the MyGo desktop UI framework.

## Horizon in-place updates and build switching

- Check for newer official builds on existing Horizon instances quietly on selection and manually from Overview or Instance Settings.
- Upgrade or switch an existing Horizon instance in place to the latest published release, another published build, or a locally cached build without reinstalling or touching worlds, mods, resource packs, shaders, or configuration.
- Show Horizon update status in the instance hero, add quick update/check/switch actions to the Overview runtime panel, and provide a build selector under Instance Settings → Native Runtime.

## Horizon addon removal and undo

- Fix removing Horizon `.hmod` files, unpacked Horizon mod folders, `.hshader` shader packs, and folder-based resource or shader packs failing with an invalid filename error when deleting through the UI's undoable removal flow.
- Restore `horizon-mods.txt` enablement state and tracked mod metadata when undoing a Horizon mod removal.

## Background installs while playing

- Allow installing and updating mods, resource packs, shaders, Horizon builds, and dependencies—and toggling, importing, or removing addons—while a game is running in the same directory, while continuing to serialize concurrent launcher tasks per directory.
- Localize busy-directory and busy-instance error messages for both Chinese and English interfaces.

## MyGo framework upgrade

- Upgrade `github.com/egoist/mygo` to `v0.10.1-0.20261122115253-94fda721a020`, incorporating MyGo 0.10.0 and subsequent desktop fixes including faster layout, Windows Direct3D 11 idle image texture release, DirectWrite registered-font deduplication, Windows touchscreen scrolling, and popup viewport clamping.

## Updating

Updates remain optional. Existing official installations can check for the release in Settings; launcher settings and Minecraft files remain in their existing locations.

For manual installation, download the archive for your operating system and processor: `.zip` for Windows, or `.tar.gz` for macOS and Linux. Extract the complete archive before launching. `amd64` is Intel/AMD x64; `arm64` includes Apple Silicon.

Windows executables are not Authenticode-signed. macOS bundles are ad-hoc signed, not notarized. See the [seed map guide](https://github.com/Viking602/YoloMCL/blob/main/docs/seed-map.md) for seed-map coverage and limitations.
