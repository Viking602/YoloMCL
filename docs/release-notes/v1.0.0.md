YoloMCL's first tagged release: a native Go launcher for Minecraft: Java Edition.

- Manage instances, modpacks, mods, resource packs, shaders, worlds, backups, and game logs.
- Browse Modrinth and CurseForge, preview skins, and track recent worlds and multiplayer servers.
- Background Java detection, cached instance loading, automatic memory allocation, and system-language selection.
- Settings now shows the version, source commit, and a GitHub icon linking to the repository.
- Future stable releases can be downloaded and installed from Settings, with signature verification and an explicit restart.

**Downloads:** choose the asset matching your OS and processor. Windows users should use the `.zip`; macOS and Linux users should use `.tar.gz`. `amd64` means Intel/AMD x64; `arm64` means ARM64, including Apple Silicon. Extract the complete archive before launching.

Windows executables are not Authenticode-signed. macOS bundles are ad-hoc signed, not notarized. Java auto-download and secure online-account persistence currently have platform limits; see the [README](https://github.com/Viking602/YoloMCL#current-platform-limits).

The `update-*.json` files and signed `.tar.gz` archives are also used by the built-in updater. Settings and Minecraft files are kept outside these update archives.
