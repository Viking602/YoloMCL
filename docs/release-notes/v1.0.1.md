YoloMCL 1.0.1 improves resource installation, desktop interactions and project organization.

## Resource discovery and installation

- Fix game-version, loader and compatibility filters for modpacks, mods, resource packs and shaders. Release-only filtering is no longer enabled by default.
- Make long version catalogs searchable and easier to navigate, and fetch additional CurseForge version pages.
- Refresh version selection and dependency previews together, with loading feedback and transitions when changing releases.
- Show per-version download counts, more precise update times and readable installation targets.
- Clear stale results when switching resource types, and reveal categories after the main content is ready.

## Desktop interface

- Improve dialog, account-menu, instance-tab and log-view transitions, along with staged number animations.
- Redesign empty states, recent-server cards, Java runtime rows and the settings header.
- Unify secondary-button sizing and contrast, and pad single-digit calendar fields.
- Confirm mod disabling with the mod's icon and name.
- Open account management and account creation as distinct actions.
- Add mouse-wheel zoom to the wardrobe preview and restore file selection when revealing a log in its folder.

## Reliability and maintenance

- Persist configuration drafts before publishing changes, and retain recovery information when modpack updates or rollback fail.
- Keep one launcher entry point and separate authentication, instance scanning, runtime options, themes and UI resources by responsibility.
- Consolidate small internal helpers and keep platform services and development-tool dependencies isolated.
- Run builds, checks and signed packaging through Bash scripts and Makefile targets.
- Expand regression coverage and rewrite the architecture document in English.

## Downloads and updates

Choose the package matching your operating system and processor. Windows users should download the `.zip`; macOS and Linux users should download the `.tar.gz`. `amd64` is Intel/AMD x64, and `arm64` includes Apple Silicon. Extract the complete archive before launching.

Existing official installations can check for this release in Settings. Update archives are signature-verified and contain application files and licenses; launcher settings and Minecraft files remain in their existing locations.

Windows executables are not Authenticode-signed. macOS bundles are ad-hoc signed, not notarized. Java auto-download and online-account credential storage retain the [current platform limits](https://github.com/Viking602/YoloMCL#current-platform-limits).
