YoloMCL 1.2.0 adds seed maps, interactive structure previews and game-preference editors, and refreshes the launcher with the new B icon and clearer controls.

## Seed maps and structure previews

- Open an instance's Seed map tab, use a saved world's seed or enter one manually, and explore the available dimensions.
- View supported biomes, surface contours, terrain, caves, ores and height slices. Inspect coordinates and biome details, copy teleport commands and locate recorded world-spawn and respawn positions.
- Search structures by translated name or identifier. Selecting a structure searches nearby automatically; changing the radius refreshes the results, and grouped markers keep overlapping results accessible.
- Inspect supported structures in a resizable, expandable 3D preview with textures, height slicing, terrain shadows, transparency and camera controls.
- Show the structure before surrounding terrain finishes loading. Reuse baked geometry, reduce rendering resolution during interaction and cancel obsolete background work when leaving a preview.
- Improve ore textures, terrain slab bottoms, the height gauge, long status messages and the visibility of preview controls and fidelity notes.
- Read saved worlds without modifying them. Predictions depend on the selected game version, effective datapacks and supported mod behavior; unsupported generators and code-generated structures retain explicit explanations. See the [seed map guide](https://github.com/Viking602/YoloMCL/blob/main/docs/seed-map.md) for coverage and limitations.

## Game preferences

- Edit global defaults or per-instance key bindings, video, audio, mouse and control settings.
- Search mod key bindings using labels from installed language resources, while retaining their original identifiers when a translation is unavailable.
- Preserve unrelated options and use revision checks to avoid overwriting changes made elsewhere.
- Create manual settings snapshots and automatic backups before saves or restoration. Restore through the existing backup flow and confirm before discarding an edited draft.

## Launcher interface

- Replace the app and window artwork, macOS bundle icon, Windows x64 executable icon and README logo with the selected B icon.
- Use lighter selectors with consistent trigger/list widths, aligned icons and selection marks, readable long labels and tooltips for text that is actually clipped.
- Improve Chinese/English text spacing, heading and status-message wrapping, changing-number widths and shared corner tokens.
- Use anchored confirmation for individual irreversible removals, dialogs for larger decisions, drawers for longer editors and pages for the main installation and log tasks.
- Keep keyboard focus and Escape behavior consistent, protect unsaved drafts and offer Undo for reversible removals.
- Show the standard official-account badge in account settings and remove redundant map-sampling indicators.
- Refresh both README editions with the new logo, feature descriptions and Awesome MyGo badge.

## Reliability

- Retry the remaining Blueprint biome providers when a selected overlay declines, rather than prematurely falling back to the original biome.
- Report mod-configuration overrides as unsupported when their Java validation has not been evaluated, instead of inferring validity from the value's shape.
- Add coverage for preview cancellation and rendering, dropdown layout, text truncation, focus, draft protection, recoverable removals and automatic structure searches.
- Keep temporary scripts, source backups, local logs and visual diagnostics out of the published source changes; tests write generated preview images to temporary directories.

## Updating

Updates remain optional. Existing official installations can check for the release in Settings; launcher settings and Minecraft files remain in their existing locations.

For manual installation, download the archive matching your operating system and processor: `.zip` for Windows, or `.tar.gz` for macOS and Linux. Extract the complete archive before launching. `amd64` is Intel/AMD x64; `arm64` includes Apple Silicon.

Windows executables are not Authenticode-signed. macOS bundles are ad-hoc signed, not notarized. Java auto-download and online-account persistence retain the [current platform limits](https://github.com/Viking602/YoloMCL#current-platform-limits).
