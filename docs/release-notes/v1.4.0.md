YoloMCL 1.4.0 adds full support for the Horizon Rust-native Minecraft client, integrates the Horizon official mod and resource registry into Discover, refreshes the desktop UI and game installer with Lobe MyGo, and enables cross-platform secure credential storage on Windows, macOS and Linux.

## Horizon native client

- Install official signed builds from `horizon-rust/horizon` with Ed25519 signature and SHA-256 verification, automatic Java 25 resource preparation, and shared build/resource caching across instances.
- Launch Horizon instances through the Microsoft ownership gate using stdin session handoff so access tokens never appear in process arguments or logs.
- Present Horizon instances accurately as a Rust-native runtime (`No JVM`) in the overview, version tags and instance settings, focusing Java configuration strictly on asset preparation while hiding inapplicable JVM memory sliders and argument fields.
- Support Horizon 26.3 in Seed maps, including biome, terrain and structure previews as well as Horizon mod-gate detection from `horizon-mods/` and `horizon-mods.txt`.

## Horizon Discover and addon management

- Add **Horizon** alongside Modrinth and CurseForge in Discover, backed by the official Horizon Content API (`horizon-rust.github.io/horizon-mods/index.json`) with revocation filtering, GitHub Release URL allowlisting, SHA-256 checks and `minisign` signature verification.
- Browse and install Horizon content/WASM mods (`.hmod`), shaders (`.hshader` / `.zip`) and resource packs (`.zip`), with automatic instance compatibility checks that prevent mixing Java mods or `.hshader` packs across runtimes.
- Manage installed Horizon mods in-place via `horizon-mods/` and `horizon-mods.txt` (enabling/disabling without renaming files), check for updates against the Horizon registry, inspect embedded and registry icons, import via file picker or drag-and-drop, and reflect Horizon mod counts and storage totals on the instance overview.
- Recognize Horizon's built-in shader runtime on the Shaders tab and read descriptions from `horizon-shaders.toml`.

## Interface and game installer

- Unify the native UI with Lobe MyGo tokens, Lucide icons, segmented controls and elevated rail states across navigation, instances, Discover, wardrobe, tasks and settings.
- Redesign the Game Installer into a responsive two-column workspace featuring a searchable Minecraft version rail, core/loader selection cards, recent build quick-picks, Java and account preflight checks, and a 3-step installation preview.
- Fix tab-switching hangs and dialog navigation stability when leaving the installer or switching pages.

## Cross-platform account storage

- Persist Microsoft and Yggdrasil / third-party login sessions across all three desktop platforms: Windows DPAPI, macOS Keychain + AES-GCM, and Linux owner-only (`0600`) local key file + AES-GCM (migrating existing Linux Secret Service keys when available).

## Updating

Updates remain optional. Existing official installations can check for the release in Settings; launcher settings and Minecraft files remain in their existing locations.

For manual installation, download the archive for your operating system and processor: `.zip` for Windows, or `.tar.gz` for macOS and Linux. Extract the complete archive before launching. `amd64` is Intel/AMD x64; `arm64` includes Apple Silicon.

Windows executables are not Authenticode-signed. macOS bundles are ad-hoc signed, not notarized. See the [seed map guide](https://github.com/Viking602/YoloMCL/blob/main/docs/seed-map.md) for seed-map coverage and limitations.
